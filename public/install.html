The stable, production version. Tracks the main branch. Drag onto the bookmarks bar (View → Show Bookmarks Bar in Chrome/Safari if it's hidden). Clicking the button here doesn't do anything useful — it has to live in your bookmarks to work.

Tracks the stage branch — unreleased changes for testing before they merge to prod. Save it as a separate bookmark from the prod one so you can compare. Expect rough edges.

How to use it

  1. Navigate to any web page with images.
  2. Click the UI Builder bookmark in your bookmarks bar.
  3. A sidebar appears on the right; the host page shifts left.
  4. Click any <img> on the page to start editing it in place.
  5. Zoom, pan, set border-radius, position the overlay, optionally swap the image.
  6. Hit Copy HTML + CSS snippet to grab the markup for your codebase.
  7. Click the ✕ to remove the sidebar entirely.

Can't drag? Add it manually

Open your bookmarks manager (Cmd/Ctrl + Shift + O in Chrome), add a new bookmark, and paste one of these into the URL field:

Prod

javascript:(()=>{const s=document.createElement('script');s.src='https://ui-builder-eosin.vercel.app/embed.js';document.head.appendChild(s)})()

Stage

javascript:(()=>{const s=document.createElement('script');s.src='https://ui-builder-stage.vercel.app/embed.js';document.head.appendChild(s)})()

Important: when you paste, make sure your browser keeps the javascript: prefix. Some browsers strip it for security if you paste into the address bar directly. The bookmarks manager keeps it intact.

Won't work on some sites

Sites with strict Content-Security-Policy (Google, GitHub, banks, internal Adobe apps) will refuse to load the script. Check the browser console for a CSP error. Try a different site to rule out bugs vs. policy.
